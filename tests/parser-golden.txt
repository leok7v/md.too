=== example-1-how-we-got-here
heading 2: How we got here|
paragraph: In 2004 John Gruber wrote down a tiny set of rules so people writing on the web could stop copying HTML angle brackets around like they were eggs. The rules fit on one page. The promise was simple: write the way you would write in a notebook, save the file as plain text, and let some small program turn it into something pleasant to read. |Less syntax, more reading.{b}| |Asterisks for emphasis. Hashes for headings. A blank line for a new paragraph.{i}| That was the whole pitch.|
paragraph: Two decades later the average Markdown editor ships with roughly the same disk footprint as a small mainframe. There is a kind of poetry in opening a 240MB application to read four paragraphs about your weekly groceries. We do not judge. We just keep a smaller tool nearby for when we want to read.|
quote:
  paragraph: "Programs are meant to be read by humans and only incidentally for computers to execute."  Hal Abelson, |Structure and Interpretation of Computer Programs{i}|. Markdown asks for the same courtesy from your text.|

=== example-5-math-the-small-kind
heading 2: Math, the small kind|
paragraph: Two engines, split by which delimiter you used, and you never pick.|
paragraph: Inline maths is typeset in the line, at the size of the words around it: |α + β = γ{math=$\\alpha + \\beta = \\gamma$}|, the right triangle staple |x² + y² = z²{math=$x^2 + y^2 = z^2$}|, Gauss's schoolboy trick |∑(i=1)ⁿ i{math=$\\sum_\{i=1\}^\{n\} i$}| (he was nine, allegedly), and |x ∈ ℝ{math=$x \\in \\mathbb\{R\}$}|. It works in a heading, |e(iπ) + 1 = 0{math=$e^\{i\\pi\} + 1 = 0$}| included, and in a table cell; a copy gives back the TeX it was written from.|
paragraph: A |$${c}| display is typeset properly, by a TeX layout engine reading the OpenType MATH table of a real maths font:|
math: \\frac\{-b \\pm \\sqrt\{b^2 - 4ac\}\}\{2a\}
paragraph: Big operators take their limits above and below, and the fences grow to fit what is inside them:|
math: \\left(\\sum_\{i=1\}^\{n\} a_i b_i\\right)^2 \\le \\left(\\sum_\{i=1\}^\{n\} a_i^2\\right)\\left(\\sum_\{i=1\}^\{n\} b_i^2\\right)
paragraph: Integrals with bounds, which the old renderer used to punt on:|
math: \\int_\{0\}^\{\\infty\} e^\{-x^2\}\\,dx = \\frac\{\\sqrt\{\\pi\}\}\{2\}
paragraph: Named operators carry their limits too, and a root can take an index:|
math: \\lim_\{n \\to \\infty\} \\sum_\{k=1\}^\{n\} \\frac\{1\}\{k^2\} = \\frac\{\\pi^2\}\{6\} \\qquad \\sqrt[3]\{\\frac\{x^2+1\}\{x-1\}\}
paragraph: Matrices, cases and aligned blocks, which it also used to punt on:|
math: \\begin\{pmatrix\} a & b \\\\ c & d \\end\{pmatrix\}^\{-1\} = \\frac\{1\}\{ad-bc\}\\begin\{pmatrix\} d & -b \\\\ -c & a \\end\{pmatrix\}
math: f(n) = \\begin\{cases\} n/2 & \\text\{if \} n \\text\{ is even\} \\\\ 3n+1 & \\text\{otherwise\} \\end\{cases\}
paragraph: An |aligned{c}| block lines its rows up on the relation between them, which is how anyone writing more than one equation expects them to sit:|
math: \\begin\{aligned\} \\nabla \\cdot \\mathbf\{E\} &= \\frac\{\\rho\}\{\\varepsilon_0\} \\\\ \\nabla \\times \\mathbf\{B\} &= \\mu_0\\left(\\mathbf\{J\} + \\varepsilon_0 \\frac\{\\partial \\mathbf\{E\}\}\{\\partial t\}\\right) \\end\{aligned\}
paragraph: Fences nest and keep growing, and scripts keep shrinking until they hit scriptscript and stop:|
math: \\left[\\frac\{\\left(\\frac\{a\}\{b\}\\right)\}\{c\}\\right] \\qquad A^\{B^\{C^\{D\}\}\} \\qquad \\frac\{\\partial u\}\{\\partial t\} = \\alpha \\nabla^2 u
paragraph: The maths alphabets are separate Unicode blocks rather than a font trick, so blackboard bold, script, fraktur, bold, sans and monospace all keep their own letters:|
math: \\mathbb\{RQZ\} \\quad \\mathcal\{ABC\} \\quad \\mathfrak\{gsl\} \\quad \\mathbf\{xyz\} \\quad \\mathsf\{uvw\} \\quad \\mathtt\{101\}
paragraph: Inline, the alphabets work the same way: |ℝ{math=$\\mathbb\{R\}$}|, |ℕ{math=$\\mathbb\{N\}$}|, |ℤ{math=$\\mathbb\{Z\}$}|, |ℚ{math=$\\mathbb\{Q\}$}|, |ℂ{math=$\\mathbb\{C\}$}|, and |\\mathcalL{math=$\\mathcal\{L\}$}| or |\\mathfrakg{math=$\\mathfrak\{g\}$}| just as well. What a surface without a typesetter shows is the Unicode spelling, which keeps the single-codepoint ones and parenthesises the rest.|
paragraph: Greek alphabet, lower and upper, in case you need both at once:|
math: \\alpha \\beta \\gamma \\delta \\epsilon \\zeta \\eta \\theta \\iota \\kappa \\lambda \\mu \\nu \\xi \\pi \\rho \\sigma \\tau \\phi \\chi \\psi \\omega
math: \\Gamma \\Delta \\Theta \\Lambda \\Xi \\Pi \\Sigma \\Phi \\Psi \\Omega
paragraph: Decorations, the kind a lecture note reaches for: braces with a label, a box around the result, a struck-out term, an arrow that stretches over its label, a symbol negated, and ink in a colour of the author's choosing.|
math: \\overbrace\{a + b + c\}^\{\\text\{three terms\}\} \\quad \\underbrace\{x_1 x_2 \\cdots x_k\}_\{k\} \\quad \\boxed\{E = mc^2\} \\quad \\cancel\{2x\} + \\underline\{y\} \\quad A \\xrightarrow\{\\ f\\ \} B \\quad a \\overset\{?\}\{=\} b \\not= c \\quad \\textcolor\{#d81b60\}\{\\text\{rose\}\} + \\color\{teal\}\\text\{teal\}
paragraph: Operators and a corner of set theory: |≤ ≥ ≠ ≈ ± × · ÷ → ⇒{math=$\\le \\ge \\neq \\approx \\pm \\times \\cdot \\div \\to \\Rightarrow$}|, |∀ x ∈ ℕ, ∃ y ∈ ℤ{math=$\\forall x \\in \\mathbb\{N\}, \\exists y \\in \\mathbb\{Z\}$}|, |A ∩ B{math=$A \\cap B$}|, |A ∪ B{math=$A \\cup B$}|, |∅{math=$\\varnothing$}|.|
paragraph: Tools that lift equations out of a PDF often forget the delimiters and leave the bare TeX sitting in a paragraph. A paragraph that opens with a control word and parses cleanly as TeX, with no ordinary words in it, is read as a display anyway:|
math: \\frac \{ D x N \} \{ \\frac \{ ( \\text \{Truth\} ) \} \{ 1 6 0 0 \\, x \\, 1 4 \} \} \\\\ \\frac \{ 4 2 8 \\, x \\, 1 0 \} \{ ( 1 ) \} \\\\ \\frac \{ 2 9 \\, x \\, 9 5 \} \{ ( 2 3 ) \}
paragraph: That is three separate tests, and prose fails all but the first: |\\alpha is the first letter{c}| parses perfectly well as alpha times i times s and so on, and is caught by the run of ordinary letters. Rows separated by |\\\\{c}|, and columns by |&{c}|, work without naming an environment.|
paragraph: There are still limits. No |\\def{c}| or |\\newcommand{c}|, and no line breaking inside a formula. A display the engine will not accept falls back to the inline spelling rather than showing you nothing, and copying any display gives you back the TeX you wrote.|

=== example-13-memory-and-performance
heading 2: Memory and performance|
paragraph: A Markdown file is just bytes. The most this reader needs to hold in memory is roughly the file size, |M ≤ c · N{math=$M \\le c \\cdot N$}|. A typical 40 KB README weighs about 50 KB once parsed, and renders in under one frame.|
paragraph: A popular Electron-based editor uses ~240 MB on disk and ~400 MB of memory per window for the same job:|
math: \\frac\{M_\\text\{electron\}\}\{M_\\text\{this\}\} \\approx 100
paragraph: A 100× memory premium for HTML rendering of plain Markdown is a choice. Reasonable people make it. We chose differently.|
heading 3: The supply-chain axis|
paragraph: The most popular JavaScript Markdown library, |marked{c}|, lists about 636 transitive packages and ~39,000 lines of code on its public dependency graph. Doing the same job in a tiny Swift codebase with zero dependencies turned out to work.|
paragraph: Pick a rough industry defect rate of |δ ≈ 15{math=$\\delta \\approx 15$}| bugs per 1,000 lines. The "code a user runs" is the app plus every dep:|
table 3x2: left,right,right
  h: [Stack] [Lines] [Expected defects]
  r: [TypeScript with `marked`] [~3.2 M] [~48,000]
  r: [This app, zero dependencies] [~2,000] [~30]
paragraph: Now the CVE side. If each dependency has a 1-in-200 chance of harboring a fresh CVE in a year, the odds |at least one{i}| dep in a tree of |N{math=$N$}| does is|
math: P = 1 - (1 - 0.005)^N
paragraph: For 636 deps that is ~96%. For 0 deps it is 0%. Every package you don't pull in is a CVE you don't have to read on a Saturday night.|

paragraph: Optimizing for the small things is just respect.|
